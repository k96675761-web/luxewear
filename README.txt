LUXEWEAR — PREMIUM FASHION DEMO WEBSITE

Files:
- index.html: website structure and content
- style.css: responsive black-and-white editorial styling
- script.js: product filters, sorting, shopping bag, newsletter demo

HOW TO USE:
1. Extract this ZIP file.
2. Open index.html in a browser to preview.
3. To publish, create a new GitHub repository named luxewear.
4. Upload index.html, style.css, script.js, and README.txt to the repository root.
5. Go to Settings > Pages.
6. Under Build and deployment, select Deploy from a branch, choose your default branch (usually main) and /(root), then Save.
7. Wait a few minutes and open the Pages URL.

NOTES:
- Product images and Google Fonts are loaded from external URLs, so internet access is needed.
- This is a demo storefront. Checkout does not process real payments.
- Prices and products are sample demo content.
