AUTOLUX — LUXURY CAR DEALERSHIP DEMO

Files:
- index.html
- style.css
- script.js

Run locally:
1. Keep all three files in the same folder.
2. Double-click index.html to open it in a browser.

Publish with GitHub Pages:
1. Create a new public repository named AutoLux.
2. Upload these three files directly into the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select branch "main" and folder "/(root)", then Save.
6. Wait a few minutes and open the URL GitHub provides.

Important:
- The car inventory, pricing, and statistics are fictional demo content.
- Images and fonts load from external websites, so internet access is required.
- In script.js, replace whatsappNumber with your own WhatsApp number (country code included, digits only).
- The enquiry form opens WhatsApp with a pre-filled message; it does not send email or store data.

Image fix update:
The vehicle cards and detail popups now use model-specific Wikimedia Commons images rather than the previous generic stock image links.
